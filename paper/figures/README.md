# Paper Figures

Figures used by the JOSS paper live in this directory so that `paper.md` can
use simple relative paths.

Recommended formats:

- Use `PDF` for vector diagrams when building the final JOSS paper.
- Use `PNG` or `JPG` for raster screenshots or photographs.
- Keep `SVG` files as editable source assets, but export a matching `PDF` if
  the JOSS/Pandoc build has trouble with SVG conversion.
