# Tutorial Media

Place short tutorial MP4 files in this folder if you want to keep local media copies in the repository.

Suggested names:

- `import-data.mp4`
- `set-fitting-window.mp4`
- `run-fitting.mp4`
- `job-list.mp4`
- `curve-view.mp4`

For GitHub pages and README files, uploading MP4 files to a GitHub issue, discussion, or release and linking to the generated URL may give a better viewing experience than committing large video files directly.
